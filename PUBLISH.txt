AUREVEIL — GITHUB PAGES

Public website:
https://jo3lbenjamin.github.io/cs2024-final-project/

Repository:
https://github.com/jo3lbenjamin/cs2024-final-project

The site is a static HTML/CSS/JavaScript project published from main, repository root.
Commit and push updated source files to main. Check GitHub Actions / Pages for the deployment result, then refresh the public site.
A purchased domain, Shopify or an on-site payment backend is not required for the assignment.

Local testing:
node scripts/server.mjs
The server defaults to http://localhost:4173. PORT may be set to use another port.

Regeneration and checks:
node scripts/build.mjs
node scripts/check.mjs

Portable alternative upload:
aureveil-publish.zip includes all 21 HTML pages, active local assets, fonts, scripts and styles. It excludes planning/source notes, reports and unused images. Host-specific canonical/Open Graph URL metadata is removed from that portable ZIP; regenerate it after edits.

The offer calculator changes on-site display only. Purchases continue through the two external Shopee links.
